# Ki-stimmen

Professionelle Telefonansagen mit KI-Stimme für Praxen und Betriebe in Edewecht und Umgebung.

## Dateien

- `plan_4_wochen.md`: Plan bis Mitte Dezember (Ziel ca. 500 €)
- `zielliste_edewecht.md`: Praxen und Betriebe zum Ansprechen, mit Status
- `NEUIGKEITEN.md`: Wer hat wann was gemacht? **Bitte nach jeder Arbeit kurz eintragen.**
- `website/`: Die Website (Startseite, Impressum, Datenschutz). Zum Ansehen `website/index.html` im Browser öffnen.
  - `website/config.js`: **Kontaktdaten hier eintragen** (Name, Adresse, Telefon, E-Mail, Hoster). Solange dort noch `TODO` steht, zeigt die Website oben einen roten Entwurfs-Balken.
  - `website/hoerproben/`: Hier kommen die drei MP3-Hörproben hinein (Dateinamen stehen in `LIESMICH.md`). Die Player auf der Website funktionieren dann automatisch.
