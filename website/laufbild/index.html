Laufbild

Lauf ein Bild durch deine Stadt.

1 · Wo?

Oder einfach auf die Karte tippen.

2 · Was?

Zeichne mit dem Finger oder der Maus eine Linie auf die Karte (ohne abzusetzen).

3 · Wie weit?

–Kilometer
–Ähnlichkeit
So kommt die Route auf deine Uhr

Strava: strava.com → Dashboard → Meine Routen → Route erstellen → GPX importieren.
Garmin: Garmin Connect → Training → Strecken → Importieren → Strecke an Gerät senden.
Komoot: komoot.com → Planen → GPX-Datei importieren.

Tipp: Lauf genau die angezeigte Linie, auch doppelte Abschnitte. Nur dann entsteht das Bild.
